# Images

Drop files here and reference them as `/assets/images/filename.jpg`.

Expected by the current config:

- `profile.jpg` — your sidebar headshot (square, ~400x400 works well)
- `logo.png` — optional small logo left of the site title (uncomment `logo:` in `_config.yml`)

Per-post header images are optional. To add one, put this in a post's front matter:

    header:
      teaser: /assets/images/my-teaser.jpg
      overlay_image: /assets/images/my-wide-header.jpg
      overlay_filter: 0.4
